## 2.1 Overview of the computing artefact

it's a place animators can share their work which others can view, and comment on. users can join and send messages in communities

right now animators post to youtube, competing for attention with other kinds of content on a saturated platform. a dedicated platform just for animators allows less popular animators get their work discovered more easily and faster

to create a webapp that allows animators to share their work, have their work easily found by other users, and connect with other animators and users

a user can upload a video with a specific thumbnail, title and description
a user can create playlists
a user can upload videos to a playlist
a user can comment on a video
a user can join a community
a user can send a message to a community
a user can upvote a video

## 2.2 Aims and objectives, scope and architecture

The app is built with SvelteKit and Cloudflare Services.

Metadata for videos, accounts, comments and playlist data are stored in D1

The video and thumbnail files are stored in R2
